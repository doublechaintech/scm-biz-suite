# Coding agent icons

Source: [Lobe Icons](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg@1.95.1`, distributed under the [MIT license](LICENSE).

Upstream filenames: `claudecode-color.svg`, `codex-color.svg`, `cursor.svg`,
`githubcopilot.svg`, `geminicli-color.svg`, `pi.svg`, `qoder-color.svg`,
`deepseek-color.svg`, `trae-color.svg`, and `opencode.svg`.
Source URL pattern:
`https://cdn.jsdelivr.net/npm/@lobehub/icons-static-svg@1.95.1/icons/<filename>`.

Each SVG mark is centered on a white rounded tile for visibility in both light and
dark GitHub themes. The marks themselves are unchanged.

`deepseek-harness.svg` uses the DeepSeek brand mark for DeepSeek Harness.
`zcode.png` is the unmodified [ZCode website icon](https://zcode.z.ai/favicon-192x192.png?v=20260707-transparent),
downloaded from the official website on 2026-10-16. It is a third-party brand
asset and is not covered by the Lobe Icons MIT license above.
